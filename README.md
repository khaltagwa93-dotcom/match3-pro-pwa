# Match-3 Pro PWA

لعبة Match-3 احترافية كاملة كـ Progressive Web App.

## الميزات
- محرك Match-3 كامل مع Specials (Striped / Wrapped / Color Bomb)
- Jelly + Ice
- 20 مستوى متوازن مع أهداف متنوعة (نقاط / جيلي)
- حفظ التقدم والنجوم والمعززات محلياً
- أصوات Web Audio
- يعمل بدون إنترنت (Service Worker)
- Accessibility + SEO + RTL عربي

## التشغيل المحلي
افتح `index.html` مباشرة أو:
```bash
npx serve .
```

## النشر
- **Vercel**: اسحب مجلد المشروع إلى [vercel.com/new](https://vercel.com/new) أو استخدم CLI بعد `vercel login`
- **Netlify Drop**: اسحب المجلد إلى [app.netlify.com/drop](https://app.netlify.com/drop)
- **GitHub Pages**: فعّل Pages من Settings → Pages → Deploy from branch (main / root)
